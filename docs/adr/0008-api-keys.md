# 0008. 증권사 앱 서버는 판매사 콘솔에서 발급한 API 키로 연동 API를 부른다

2026-11-13 · 결정됨(2026-11-13 구현) · [0007](0007-openapi-and-channel-sample-app.md)의 API 문서에 인증 방식을 더한다

## 맥락

[0007](0007-openapi-and-channel-sample-app.md)로 API를 OpenAPI 문서로 제공한다. 판매사의 증권사 앱 서버가 이 문서를 보고 `판매 채널 연동` API를 부른다.

지금까지 인증은 접근 코드(`DEMO_TOKEN`) 하나였다. 서버에 접근 코드를 설정했을 때만 검사하고, 모든 경로를 열었다. 판매사 콘솔과 증권사 앱 예시가 같은 코드를 썼다. 외부 앱에 API를 주려면 다음이 필요하다.

- 앱마다 다른 키. 한 앱의 키가 새어도 그 키만 폐기한다.
- 범위. 연동 앱은 고객 처리 API만 부르고, 기준·상품 등록이나 관리자 승인은 부르지 못한다.
- 키별 요청 한도와 사용 기록.

## 결정

- **API를 부르는 쪽을 둘로 나눈다.** 판매사 직원은 판매사 콘솔에서 접근 코드로 쓴다. 증권사 앱 서버는 API 키로 부른다. 로그인(계정, SSO)은 MVP 밖이다. 접근 코드가 그 자리를 대신한다.
- **API 키는 판매사 콘솔의 API 키 화면에서 발급하고 폐기한다.** 경로는 `GET /api/keys`, `POST /api/keys`, `POST /api/keys/:id/revoke`다. 이 경로는 `판매사 콘솔` 분류다. API 키로는 부를 수 없다.
- **키 원문은 발급 응답에만 한 번 나온다.** 형식은 `fvk_`와 임의 문자 32자다. 저장소(로컬 파일, Vercel Redis)에는 SHA-256 해시, 이름, 앞 12자, 만든 시각, 마지막 사용 시각, 폐기 시각만 둔다. 폐기한 키도 기록으로 남긴다.
- **범위는 OpenAPI 분류와 같다.** API 키는 `판매 채널 연동` 분류의 경로만 부른다. 다른 경로는 403이다. 범위는 `channel` 하나다.
- **API 키는 접근 코드 설정과 관계없이 항상 확인한다.** `fvk_`로 시작하는 값을 보내면 없는 키나 폐기한 키는 401이다. 접근 코드는 지금처럼 서버에 설정했을 때만 검사한다.
- **요청 한도는 키마다 센다.** 분당 120번이다. 키가 없거나 모르는 키면 IP마다 센다.
- **마지막 사용 시각은 1분 단위로 기록한다.** 1분 안에 다시 쓰면 저장소에 쓰지 않는다.
- **사용 중인 키는 20개까지다.**
- **증권사 앱 예시(`/channel/`)는 접근 코드를 그대로 쓴다.** 실제 앱은 키를 서버에 둔다. 예시는 브라우저만으로 동작하므로 키를 쓰지 않는다.

## 이유

- 키를 앱마다 나누면 유출과 폐기의 범위가 키 하나로 줄어든다.
- 범위를 문서 분류와 같게 두면 판매사 개발자가 문서만 보고 키로 부를 수 있는 경로를 안다. 경로를 추가할 때 분류 하나만 정하면 범위도 정해진다.
- 해시만 저장하면 저장소가 새어도 키 원문은 나가지 않는다.
- 사용 시각을 1분 단위로 쓰면 조회 요청마다 저장소 잠금을 잡지 않는다.

## 대가

- 원장에는 판매사 계정이 하나다. 키는 한 판매사 안의 앱을 나눈다. 여러 판매사를 받으려면 판매사마다 원장 역할과 저장소가 필요하다. MVP 이후 결정이다.
- 콘솔은 여전히 접근 코드 하나로 연다. 직원별 계정과 감사 기록은 없다.
- 키를 쓰는 요청은 저장소를 한 번 더 읽는다(Vercel에서 다른 인스턴스가 발급·폐기한 결과를 반영한다). 마지막 사용 시각을 쓸 때는 잠금을 한 번 잡는다.
- 요청 한도는 인스턴스마다 센다. Vercel 인스턴스가 여러 개면 실제 한도가 더 크다.

## 검토한 대안

- **접근 코드만 유지.** 가장 단순하다. 앱마다 폐기할 수 없고, 연동 앱이 콘솔 API까지 부른다.
- **범위를 경로마다 따로 정의.** 세밀하다. 분류와 범위를 두 곳에서 관리하게 된다.
- **OAuth 2.0 클라이언트 자격 증명.** 표준이고 토큰 만료가 있다. 토큰 발급 서버와 키 순환이 필요해 MVP 범위를 넘는다.
- **환경 변수로 키 목록을 설정.** 화면이 필요 없다. 발급과 폐기에 배포가 필요하다.
