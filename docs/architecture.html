저장소와 테스트

Node.js 22와 npm 10 workspaces를 쓴다. JS 의존성은 스캐폴딩 때 lockfile로 고정한다. forge test로 원장을 검증한다. node:test와 Fastify inject로 API를 검사한다. Playwright로 웹 가입과 원장 조회를 연결해 확인한다.

링크 공유용 환경

Vercel에 React 웹을, Render에 Fastify API를, Sepolia에 Solidity 계약을 배포한다. 증명 파일과 테스트 서명 키는 API 쪽에 둔다. Render 무료 인스턴스는 유휴 시 중지될 수 있으므로 발표는 로컬 구성을 기본으로 잡는다.
