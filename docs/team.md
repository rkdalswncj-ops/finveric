## 개발이 넘겨주는 것

- **시연 환경.** Docker 명령 하나로 각자 컴퓨터에서 실행한다. 순서는 [README의 실행하기](../README.md#-실행하기)를 따른다. 영상도 이 환경에서 촬영한다.
- **그림.** `docs/assets/`의 PNG를 PPT에 그대로 넣는다. SVG는 크게 키워도 깨지지 않는다.
- **화면 캡처.** `docs/assets/screens/`에 1440×900 PNG로 둔다. 다른 화면이 필요하면 개발 담당에게 요청한다.
- **시연 순서와 수치.** 발표 순서는 [실행과 시연](runbook.md), 기대 결과는 [PRD](prd.md#기말-시연-시나리오)에 있다.

## 팀원이 넘겨주는 것

- **조사 결과.** [시장 조사](market-research.md)에 반영한다. 출처 링크와 확인 날짜를 함께 적는다.
- **발표 흐름.** 발표 순서가 바뀌면 시연에 필요한 화면과 데이터를 개발 담당에게 알린다.

## 파일 규칙

- PPT와 영상 원본은 공유 드라이브에 둔다. 영상 재생 위치는 위 표에 적는다.
- 글로 된 자료(조사 결과, 대본 초안)는 GitHub 웹에서 마크다운 파일을 바로 고칠 수 있다.
- 개인 계정이 드러나는 주소나 개인 정보는 문서에 쓰지 않는다.
