ELS 가입에서 ZKP와 스마트컨트랙트의 역할

ZKP는 답변을 공개하지 않고 조건 충족을 증명한다. 스마트컨트랙트는 증명과 서명 확인을 검사해 가입을 확정한다.

모의 가입 A7 · 규칙 v1

고객이 확인한 답변에 증명을 묶는 방법

가입 ID, 진단 회차, 상품, 규칙 버전, 답변과 비공개 임의값을 묶어 커밋먼트를 만든다. 본인 확인 서비스가 고객이 이 값을 확인했다는 증빙에 서명한다고 가정한다. 컨트랙트는 증빙을 검증하고 커밋먼트를 회차별로 한 번 등록한다. 등록값과 일치하는 증명만 받는다.

서명 확인과 실제 이해 여부

판매사는 전자서명을 확인하고 해당 가입 건·회차·서명 계약서 해시를 묶어 확인 증빙을 발행한다. 컨트랙트는 승인된 판매사의 증빙과 ZKP를 같은 요청에서 검사하고 확정 상태를 기록한다. 고객의 실제 이해 여부는 별도로 확인한다.
