ELS 진단과 가입 조건을 코드로 실행

스마트컨트랙트가 진단을 채점한다. 판정과 필수 절차를 확인해 가입을 확정한다.

스마트컨트랙트가 실행하는 규칙

  1. 가입을 시작할 때 상품과 규칙 버전을 고정한다. 필수 문항마다 허용한 선택지가 하나씩 있는지 확인한다.
  2. 선택지 점수를 합산하고 상품의 가입 기준과 비교한다. 시연에서는 두 문항 합계가 3점 이상이면 적합이다.
  3. 재진단은 회차를 추가한다. 새 진단에 연결된 판정과 필수 설명 확인으로 가입을 심사한다.
  4. 적합 판정 뒤에 설명 확인 답변을 검사한다. 원금 손실 문항에 통과하고 서명 증빙이 있어야 확정한다. 화면 시연은 서명 증빙이 있다고 가정한다.

시연과 운영의 데이터 경계

기말 MVP · 가상 답변 직접 채점
ELS 한 종류의 가상 선택지를 Sepolia 트랜잭션으로 보낸다. 입력값은 공개되므로 실제 고객 응답이나 신원 정보를 사용하지 않는다.
운영 확장 · 답변을 감춘 판정 검증
응답 원문을 외부에 보관하고, 같은 가입 건·규칙 버전·응답에 대한 채점이 맞다는 영지식 증명을 컨트랙트에서 확인하는 방식을 검토할 수 있다.
고객 답변과 증명서
고객이 확인한 답변 묶음에 가입 ID, 규칙 버전, 진단 회차를 묶어 서명하는 방식을 검토한다. 채점은 제출된 답변을 기준으로 한다. 가입 후 증명서는 적용 규칙과 판정이 원장 기록에 맞는지 확인할 때 쓴다.
