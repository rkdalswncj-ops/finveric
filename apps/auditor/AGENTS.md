# auditor 앱 작업 규칙

감독기관·외부 검증자(B2G)가 쓰는 독립 검증 앱이다. 배포에서는 같은 도메인의 `/auditor/`에서 실행한다. 화면을 고치기 전에 루트 [DESIGN.md](../../DESIGN.md)를 읽는다.

## 검증 경로

| 경로 | 판매사 API | 원장 |
| --- | --- | --- |
| 가입 이력에서 검증 | 선택한 판매 건의 영수증과 원본만 GET으로 받는다 | 브라우저가 지정 RPC·컨트랙트로 대조한다 |
| 파일로 검증 (`?source=file`) | 호출하지 않는다 | 브라우저가 지정 RPC·컨트랙트로 대조한다 |

- 이 앱은 판매사 API에 POST를 보내지 않는다. 기록을 바꾸는 기능을 넣지 않는다.
- 검증 판정은 `packages/core/src/verify.ts`를 쓴다. 화면에서 다시 구현하지 않는다.
- 원본 일치와 가입 조건 검증 완료를 구분해 표시한다.

## 코드

- 검증 설정은 사이트 루트의 `/deployment.json`에서 읽는다(`useDeployment`). 이전 원장은 `/deployment-v1.json`~`v3`을 읽는다.
- Vite `base`는 `/auditor/`, 개발 서버는 5174 포트다.
- 두 앱이 함께 쓰는 요소는 `packages/ui`에 둔다.
