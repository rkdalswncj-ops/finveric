# client 페이지 작업 규칙

판매사 소비자보호 담당(B2B)이 쓰는 판매사 콘솔이다. 판매 채널 시연(증권사 앱 재현)도 여기에 있다. 화면을 고치기 전에 루트 [DESIGN.md](../../../../DESIGN.md)를 읽는다. 업무 규칙은 [PRD](../../../../docs/prd.md)를 따른다.

## 메뉴와 경로

페이지는 `/client/` 아래에서 실행한다(라우터 `basename`). 아래 경로는 그 안의 경로다.

| 묶음           | 경로                                                                                  | 화면                                                              |
| -------------- | ------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| 판매사 업무    | `/`, `/rules`, `/products`, `/review`, `/signals`, `/chain`                           | 대시보드, 진단 기준, 상품 관리, 판매·검토, 위험 신호, 온체인 처리 |
| 판매 채널 시연 | `/channel`, `/channel/fund`, `/channel/enroll`, `/channel/records`, `/channel/verify` | 상품 찾기, 상품 상세, 가입하기, 내 가입 기록, 가입 기록 확인      |

- 판매사 업무 화면의 문구는 합니다체로 쓴다. 판매 채널 시연은 "증권사 앱에서 고객이 보는 화면"이다. 이 묶음의 문구는 해요체로 쓰고, 블록체인 용어는 "기술 정보 보기"에 접어 둔다.
- 가입하기는 최대 480px 한 열이다. 진단(한 화면에 한 문항) → 결과 → 적합성 → 핵심 설명 카드 5장 → 녹취 동의(대상만) → 청약 → 숙려 → 최종 확인 → 증명서 순서다. 청약 전에는 언제든 가입을 중단할 수 있다. 진단 회차는 원장에 남고 다음 가입에서 이어진다.
- 3회차 이상 진단한 고객의 청약은 판매·검토의 "관리자 승인" 뒤에 한다. "준법"은 쓰지 않는다.
- 가입 기록 확인(`/channel/verify`)은 고객이 증명서로 기록을 확인하는 모습을 보여 주는 테스트 화면이다. 판매사 API를 부르지 않고 `verifySale`(동적 import)로 지정 RPC의 원장과 대조한다. 결과는 `일치`, `불일치`, `기록 없음`만 쓴다.
- 판매 채널 경로는 `links.ts`의 `channel`로 만든다. 경로 문자열을 화면에 직접 쓰지 않는다.
- 감독기관 화면은 `/auditor/` 페이지다. `auditorUrl()`로 링크한다.

## 코드

- 화면마다 `screens/` 아래 파일 하나를 둔다. 여러 화면이 함께 쓰는 표시 계산은 `sales.ts`(판매 건 상태, 상품·기준 찾기, 위험 신호 입력), `traces.ts`(처리 기록 이름·상태)에 둔다. 함께 쓰는 표시 요소는 `components.tsx`에 둔다.
- `App.tsx`가 기준, 상품, 판매 건, 처리 기록, 시연 고객의 회차를 한 번에 읽는다. 화면은 `run()`으로 처리를 부르고, 끝나면 모두 다시 읽는다. 시연 고객 번호는 `/api/config`의 `demoCustomer`를 쓴다.
- API는 `packages/ui`의 `api()`로 부른다. 응답 타입과 요청 본문은 `packages/core/src/api.ts`의 DTO를 쓴다.
- 진단 기준 검사·판정(`validateRule`, `evaluateRule`, `ruleHash`), 상품 검사(`validateProduct`), 적합·녹취 대상(`isSuitable`, `isProtectedSale`), 위험 신호(`computeSignals`), 검증(`verifySale`)은 `packages/core`를 쓴다. 화면에서 다시 구현하지 않는다.
